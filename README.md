<h1 align="center">📱 QDEC Citizen</h1>

<p align="center">
  <b>Quick Digital Evidence Collector - Citizen Application</b>
</p>

<p align="center">
  A secure Android application that enables citizens to submit digital evidence,
  report incidents, and track case status efficiently.
</p>

---

<h2>🚀 Features</h2>

<ul>
  <li>🔐 Secure User Authentication</li>
  <li>📸 Image Evidence Upload</li>
  <li>🎥 Video Evidence Upload</li>
  <li>📄 Document Submission</li>
  <li>📍 Incident Location Support</li>
  <li>📋 Case Tracking System</li>
  <li>🔔 Real-Time Status Updates</li>
  <li>☁️ Firebase Cloud Integration</li>
</ul>

<h2>📂 Application Flow</h2>

```text
Citizen Login/Register
          ↓
Create Incident Report
          ↓
Upload Evidence
          ↓
Submit Details
          ↓
Firebase Database
          ↓
Admin Review
          ↓
Case Status Updated
```

<h2>🎯 Project Objective</h2>

<p>
QDEC Citizen is designed to simplify the process of reporting incidents
and submitting digital evidence. The application provides a secure,
user-friendly, and efficient platform for communication between citizens
and authorities.
</p>
